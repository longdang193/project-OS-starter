# Intent

The intent layer records stable project purpose and outcome decisions for `<project-name>`.

Use these docs before changing direction, scope, audiences, or success criteria:

- `project-charter.md`: purpose and problem statement
- `constraints-and-non-goals.md`: boundaries and deliberate exclusions
- `stakeholders.md`: audiences, owners, and reviewers
- `success-outcomes.md`: what success looks like and how it is checked

Intent docs should stay concise and durable. They are not run logs, changelogs, or task trackers.
